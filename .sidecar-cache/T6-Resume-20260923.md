## Regex Pattern Verification

Pattern: `^[cC]:[a-zA-Z0-9_-]+$`

Character class `[a-zA-Z0-9_-]` breakdown:
- `a-z` - range a-z
- `A-Z` - range A-Z  
- `0-9` - range 0-9
- `_` - underscore (literal)
- `-` - dash (literal at end of character class)

This pattern correctly matches C: prefixed commands like `C:LITHP`, `C:LITHP-MGR`, `C:LITHP-INIT`.
