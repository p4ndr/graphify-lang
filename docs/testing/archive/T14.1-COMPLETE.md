## Key Findings

1. **Modular architecture**: Each responsibility has its own .lsp file with
   a unique prefix (pvc-<mod>: for public, pvc-<mod>:_ for private)

2. **Visual LISP heavy**: Uses vl-*, vla-*, vlax-* for AutoCAD COM
   integration

3. **TOML settings**: Custom TOML subset reader (pvc-tml:) validates
   pvc_tagtool.toml with a strict schema

4. **XDATA backup**: Packed asset tags in PVC_TAGTOOL application with
   version marker PVCX1

5. **Round-trip CSV**: UTF-8 with BOM, handle-keyed, Excel-compatible

6. **Error handling**: pvc-err:trap and pvc-err:safe-call guard all COM
   and file operations

7. **COM undo marks**: pvc-err:undo-start / pvc-err:undo-end for atomic
   operations
