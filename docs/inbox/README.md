# Inbox

Drop files here for the agents to ingest (any format; a date prefix such as `2026-09-20_notes.md` is optional).

- Agents ingest this folder at the start of each session, following `docs/15-INBOX.md`.
- An ingested file moves to `processed/`; `docs/15-INBOX.md` §3 records where its content went.
- Only this README is in git.
