## 2. Internal Functions (pvc- prefix)

Functions prefixed with `pvc-` are internal module functions. Each module has its own namespace prefix:

| Module | Function Prefix | Description |
|--------|-----------------|-------------|
| app | `pvc-app:_*`, `pvc-app:*` | Application entry points, settings, file operations |
| asg | `pvc-asg:_*`, `pvc-asg:*` | Assigner registry and management |
| blk | `pvc-blk:_*`, `pvc-blk:*` | Block definition and INSERT entity operations |
| cfg | `pvc-cfg:_*`, `pvc-cfg:*` | Settings validation and model building |
| csv | `pvc-csv:*` | CSV writer and reader |
| dif | `pvc-dif:_*`, `pvc-dif:*` | Reconcile plan computation (pure) |

### Extraction Recommendations for graphify-lang

1. **Command Functions**: Extract all `C:` prefixed functions as AutoCAD command symbols

2. **Module Functions**: Extract all `pvc-<module>:` functions with their module namespace

3. **Private Helpers**: Extract all `pvc-<module>:_*` functions as internal helpers

4. **Global Variables**: Extract all `*pvc-<module>:*` variables as module-level state

5. **Dependencies**: Track module dependencies (e.g., `pvc-rec:` depends on `pvc-utl:`, `pvc-err:`, `pvc-log:`, `pvc-blk:`, `pvc-dif:`)

6. **Data Structures**: Extract record schemas from `defun` docstrings (e.g., SRS 6.3 reference records, model records)

7. **Constants**: Extract configuration constants (alignment table, XDATA types, sync policy, etc.)

8. **Error Handling**: Track error patterns (`pvc-err:trap`, `pvc-err:safe-call`)

9. **COM/ActiveX**: Track ActiveX method calls via `vla-` and `vlax-` prefixes

10. **File Operations**: Track file I/O patterns (CSV, TOML, log files, temp files)

### Testing Strategy

The code structure suggests these test categories:

1. **Command Tests**: `PVCTEST`, `PVCTESTX`, `PVCTESTNOD` - verify commands work correctly
2. **Module Tests**: Each module has its own test file (e.g., `pvc_test_blk.lsp`)
3. **Integration Tests**: Full workflow tests (extract → reconcile → round-trip)
4. **Harness Tests**: Verification against harness facts (P1-P8, F1-F8, SC1-SC5)
