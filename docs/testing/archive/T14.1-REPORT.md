## Extraction Patterns

### Block Selection
1. Load settings from pvc_tagtool.toml
2. Define block groups (string, combiner) with name patterns and layers
3. Select INSERT entities on matching layers
4. Classify by effective name patterns
5. Build reference record with group/index

### Asset Tags (8 total)
- PCS (substation)
- PCU (power conversion unit)
- DCDC
- CBX (circuit breaker)
- CCT (circuit number)
- STR (string number)
- COMBINER
- CABLES (stringing MTEXTs)

### XDATA Format
- Application: PVC_TAGTOOL
- Packed copy: PVCX1;<tag1>;<tag2>;...;<tag8>
- Separator: ;
- Escape: \
